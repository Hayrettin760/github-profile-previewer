## 📌 Proje Hakkında / About / Über das Projekt

<details>
<summary><b>🇹🇷 Türkçe</b></summary>

Bu uygulama, kullanıcıların herhangi bir GitHub kullanıcı adını girerek ilgili profilin avatarını, ismini, biyografisini, kamuya açık depo (repository) ve takipçi sayılarını anlık olarak sorgulayabileceği şık bir web arayüzüdür.
</details>

<details>
<summary><b>🇺🇸 English</b></summary>

This application is a stylish web interface where users can enter any GitHub username to instantly query and view the profile's avatar, name, bio, public repository count, and follower count.
</details>

<details>
<summary><b>🇩🇪 Deutsch</b></summary>

Diese Anwendung ist eine stilvolle Web-Oberfläche, mit der Benutzer jeden GitHub-Benutzernamen eingeben können, um Avatar, Name, Biografie, Anzahl der öffentlichen Repositories und Follower-Zahlen sofort abzufragen.
</details>

## ✨ Öne Çıkan Özellikler / Features / Funktionen

<details>
<summary><b>🇹🇷 Türkçe</b></summary>

* 🌍 **Çok Dilli Destek:** Türkçe (TR), İngilizce (EN) ve Almanca (DE) dilleri arasında bayrak butonlarıyla anında geçiş imkanı.
* ⚡ **Canlı API Entegrasyonu:** GitHub REST API üzerinden `async/await` mimarisi ile gerçek zamanlı veri çekme.
* 🎨 **Modern & Estetik Tasarım:** Koyu tema, yuvarlatılmış kavisli kart yapısı (`border-radius: 30px`), ortalanmış düzen (`margin: auto`) ve özel tipografi.
* 📱 **Tam Uyumlu:** Farklı ekran boyutlarında ve cihazlarda pürüzsüz görünüm.
</details>

<details>
<summary><b>🇺🇸 English</b></summary>

* 🌍 **Multi-Language Support:** Instant switching between Turkish (TR), English (EN), and German (DE) via flag buttons.
* ⚡ **Live API Integration:** Real-time data fetching via GitHub REST API using `async/await`.
* 🎨 **Modern & Aesthetic Design:** Dark theme, rounded card layout (`border-radius: 30px`), centered alignment (`margin: auto`), and clean typography.
* 📱 **Responsive Design:** Seamless appearance across various screen sizes and devices.
</details>

<details>
<summary><b>🇩🇪 Deutsch</b></summary>

* 🌍 **Mehrsprachige Unterstützung:** Sofortiger Wechsel zwischen Türkisch (TR), Englisch (EN) und Deutsch (DE) über Flaggen-Schaltflächen.
* ⚡ **Live-API-Integration:** Echtzeit-Datenabruf über die GitHub-REST-API mit `async/await`.
* 🎨 **Modernes & Ästhetisches Design:** Dunkles Theme, abgerundete Kartenstruktur (`border-radius: 30px`), zentriertes Layout (`margin: auto`) und saubere Typografie.
* 📱 **Responsive Design:** Nahtlose Anzeige auf verschiedenen Bildschirmgrößen und Geräten.
</details>

## 🛠️ Kullanılan Teknolojiler / Tech Stack / Technologien

* **HTML5:** Sayfa yapısı ve anlamsal etiketler / Semantic page structure.
* **CSS3:** Flexbox, özel renk paleti, `margin: auto` ile ortalama, kavisli kenarlar ve gölge efektleri.
* **JavaScript (ES6+):** Fetch API, dinamik DOM manipülasyonu ve dil nesnesi (dictionary) yönetimi.
* **Font Awesome & FlagCDN:** İkonlar ve cihaz bağımsız net bayrak görselleri.
