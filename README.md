# 🚀 GitHub Profile Previewer

Modern, koyu mod (dark mode) arayüzüne sahip, çok dilli (TR/EN/DE) dinamik GitHub profil önizleme uygulaması.

## 📌 Proje Hakkında
Bu proje, kullanıcıların herhangi bir GitHub kullanıcı adını girerek ilgili profilin avatarını, ismini, biyografisini, kamuya açık depo (repository) ve takipçi sayılarını anlık olarak sorgulayabileceği şık bir web arayüzüdür.

## ✨ Öne Çıkan Özellikler
* 🌍 **Çok Dilli Destek:** Türkçe (TR), İngilizce (EN) ve Almanca (DE) dilleri arasında anında geçiş imkanı.
* ⚡ **Canlı API Entegrasyonu:** GitHub REST API üzerinden `async/await` mimarisi ile gerçek zamanlı veri çekme.
* 🎨 **Modern & Estetik Tasarım:** Koyu tema, yuvarlatılmış kavisli kart yapısı (`border-radius`), ortalanmış düzen ve özel tipografi.
* 📱 **Tam Uyumlu (Responsive):** Farklı ekran boyutlarında sorunsuz görüntülenme.

## 🛠️ Kullanılan Teknolojiler
* **HTML5:** Sayfa yapısı ve anlamsal etiketler.
* **CSS3:** Flexbox, özel renk paleti, `margin: auto` ile ortalama, kavisli kenarlar ve gölge efektleri.
* **JavaScript (ES6+):** Fetch API, dinamik DOM manipülasyonu ve dil nesnesi (dictionary) yönetimi.
* **Font Awesome & FlagCDN:** İkonlar ve cihaz bağımsız net bayrak görselleri.
