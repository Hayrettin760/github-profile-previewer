## 🇺🇸 English

### 📌 About The Project
This application is a stylish web interface where users can enter any GitHub username to instantly query and view the profile's avatar, name, bio, public repository count, and follower count.

### ✨ Features
* 🌍 **Multi-Language Support:** Instant switching between English (EN), Turkish (TR), and German (DE) via flag buttons.
* ⚡ **Live API Integration:** Real-time data fetching via GitHub REST API using `async/await`.
* 🎨 **Modern & Aesthetic Design:** Dark theme, rounded card layout (`border-radius: 30px`), centered alignment (`margin: auto`), and clean typography.
* 📱 **Responsive Design:** Seamless appearance across various screen sizes and devices.

### 🛠️ Tech Stack
* **HTML5:** Semantic page structure.
* **CSS3:** Flexbox, custom color palette, centered alignment (`margin: auto`), rounded corners, and shadow effects.
* **JavaScript (ES6+):** Fetch API, dynamic DOM manipulation, and language dictionary management.
* **Font Awesome & FlagCDN:** Icons and crisp, device-independent flag images.
